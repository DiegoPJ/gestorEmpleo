# Frontend Angular

Aplicacion cliente para gestionar candidaturas, empresas, contactos, recordatorios, notificaciones y preparacion de entrevistas.

## Pantallas previstas

- Login
- Registro
- Dashboard
- Candidaturas
- Detalle de candidatura
- Empresas
- Contactos
- Recordatorios
- Notificaciones
- Preparacion de entrevistas
- Preguntas frecuentes
- Apuntes tecnicos
- Plantillas

## Primeros comandos

```bash
npm install
npm start
```
